### 👨‍💻 About Me

I'm a backend engineer with 3+ years of professional experience building production platforms for e-commerce and digital-goods automation. I work mainly in **Node.js, TypeScript and NestJS** on **MongoDB**, with PostgreSQL and Redis, and I'm comfortable across the full MERN stack when a feature needs the interface too.

I'm drawn to the parts of a platform that have to be reliable: third-party marketplace integrations, secure payment and settlement flows, idempotent webhook processing, and real-time delivery. Currently at **AutoDrop**, I design the backend of a multi-tenant dropshipping and marketplace automation platform.

- 💬 Ask me about: Node.js, NestJS, TypeScript, MongoDB, PostgreSQL, React.js, Next.js
- 🌐 Portfolio: **[portfollio-omar.vercel.app](https://portfollio-omar.vercel.app/)**

### ⚡ Highlights

- 🔌 Integrated **Shopify, Salla, Zid, AliExpress and SoBuy** on one shared, extensible connector layer with secure OAuth2 authorization
- 🪝 Built a webhook pipeline (signature validation, idempotent handlers, automated failure recovery) processing **10,000+ events/day** and **300+ orders/day**
- 💳 Owned payment and settlement flows (instant settlement lifecycle, cancel/refund, reconciliation) plus incident-response tooling supporting **1,000+ merchants**
- ⏱️ Real-time delivery with **Socket.IO**, background jobs with **BullMQ and Redis**
- 🔐 Implemented a full **RBAC** permission system, bilingual (AR/EN) support, and optimized MongoDB aggregations
- 🤖 Integrated **Google Gemini** into production workflows for AI-assisted content generation, catalog classification and pricing automation

### 🚀 Selected Work

- **[AutoDrop](https://portfollio-omar.vercel.app/)**: Multi-tenant dropshipping and marketplace automation platform (Node.js · TypeScript · NestJS · MongoDB · Redis · BullMQ). Product sync, order orchestration that splits mixed carts and routes lines to suppliers, subscription billing, settlements, and real-time merchant updates.
- **Drop Card**: Digital dropshipping platform that unifies digital and service products in one merchant dashboard, with a multilingual AI content pipeline and automated wallet and settlement reconciliation.
- **B-Care**: Insurance comparison platform for a licensed Saudi brokerage, with real-time quote comparison and instant policy issuance.
- **TICKETS.EG**: Backend APIs and provider integrations for Egypt's flight search aggregator, with real-time fares from 1,200+ airlines and travel providers, price alerts, and search performance tuning.
- **Egypt Laptop**: REST APIs for the storefront and checkout flow, plus an admin dashboard for store operations.
- **Family Foods**: Backend for a cross-platform (Flutter + web) food ordering app with Fawry, Tab and Paymob payments, and a real-time order tracking admin platform.

📄 More details and live previews on my **[portfolio site](https://portfollio-omar.vercel.app/)**.
